👨‍💻 HR Analytics Dashboard using Microsoft Excel
📌 Project Overview

This project focuses on analyzing employee data to gain valuable workforce insights. The dashboard provides a comprehensive view of employee distribution, salary trends, attrition analysis, performance ratings, and project allocation. The objective is to help HR teams make data-driven decisions for workforce planning, employee retention, and organizational growth.

🎯 Project Objectives
Analyze workforce distribution across departments and locations
Monitor employee attrition and retention trends
Evaluate salary structures and compensation patterns
Assess employee performance through appraisal ratings
Identify skill distribution and project allocation
Support strategic HR decision-making
